# Настройка tmux в этом форке airgeddon

В этом форке утилиты в tmux-режиме запускаются **панелями в одном окне**, а не отдельными окнами. Текст из панелей можно выделять и копировать (мышь в сессии включена).

## 1. Включить tmux вместо xterm

Нужен установленный `tmux`. Дальше любой из способов:

**Меню airgeddon:** Options → переключить Windows handling с xterm на tmux. После этого **перезапусти скрипт**.

**Файл `.airgeddonrc`** (лежит рядом со скриптом или в `/etc/`):

```
AIRGEDDON_WINDOWS_HANDLING=tmux
```

**Один запуск без правки rc:**

```bash
sudo AIRGEDDON_WINDOWS_HANDLING=tmux ./airgeddon.sh
```

## 2. Панели (включены по умолчанию)

Пока `AIRGEDDON_WINDOWS_HANDLING=tmux`, утилиты открываются панелями:

| Сколько утилит | Раскладка |
|---|---|
| 1 | меню слева, утилита справа |
| 2 | меню сверху на всю ширину, две утилиты снизу |
| 3 | сетка 2×2: меню слева сверху, остальные панели — утилиты (в том числе Control) |
| 4+ | сетка tiled |

Фокус остаётся на меню airgeddon.

Отключить панели и вернуть старые отдельные tmux-окна:

```
AIRGEDDON_TMUX_PANES=false
```

Если переменной нет в существующем `.airgeddonrc`, скрипт сам подставит `true`.

## 3. Копирование из панелей

В сессии включён `mouse on`. Выделяй текст мышью — tmux копирует в свой буфер. Вставка: `Ctrl+b` затем `]`.

Если хочешь системный буфер обмена (нужны `xclip` или `wl-clipboard`):

```
tmux show-buffer | xclip -selection clipboard
```

Либо в `~/.tmux.conf`:

```
set -g mouse on
bind -T copy-mode-vi MouseDragEnd1Pane send-keys -X copy-pipe-and-cancel "xclip -selection clipboard -in"
```

## 4. Навигация

- Между панелями: `Ctrl+b` затем стрелка, или клик мышью.
- Масштаб одной панели на весь экран: `Ctrl+b` затем `z` (ещё раз — обратно).
- Не закрывай панель меню (`airgeddon-Main`) — это сам скрипт.
